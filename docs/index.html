Firebase AI Logic Architecture

Workload-matched Hybrid Inference across all 3 modes

Instead of firing 10+ cloud requests per hour-long lecture, LectureLens AI matches each task to the right engine using firebase/ai and firebase/app-check.

PREFER_ON_DEVICE

Notes, Flashcards & Analogies

Runs privately on Chrome Gemini Nano across up to 12 lecture chapters with grammar-constrained JSON schemas ( minItems / maxItems).

  • Zero rate-limit quota burn
  • Automatic single-call Cloud fallback if Nano isn’t ready yet
ONLY_IN_CLOUD

Full-Lecture Practice Quiz

Sends up to 60,000 characters in one sequential call to Gemini 3.8 Flash protected by MV3-safe Firebase App Check.

  • Cross-chapter 5–12 question comprehension tests
  • Prevents duplicate questions & cloud request bursts
ONLY_ON_DEVICE

Strict Local-Only Privacy Lock

Switch to Local-Only anytime to block all outbound Cloud calls and keep sensitive study materials 100% on your machine.

  • Works completely offline once Nano is downloaded
  • All Study History stays in your local Chrome profile
Bidirectional Cloud → On-Device Tutor Loop

Miss a question in the Cloud Quiz? Clicking Explain Simply (Nano) routes just that concept back to on-device Gemini Nano for an instant everyday analogy and key takeaway.

Try It in Chrome

3-Step Judge & Developer Setup

Requires desktop Chrome 138+ (with Built-in Prompt API flags enabled for local Gemini Nano) and a Firebase AI Logic project for Cloud Quiz & fallback.

1

Enable Chrome Gemini Nano Flags

Open both Chrome flags below, set Optimization Guide On Device Model to Enabled BypassPerfRequirement and Prompt API for Gemini Nano to Enabled, then relaunch Chrome. 

chrome://flags/#optimization-guide-on-device-model
chrome://flags/#prompt-api-for-gemini-nano
2

Clone, Configure .env, and Build

Copy .env.example to .env with your Firebase Web App credentials and App Check debug setting (VITE_APPCHECK_DEBUG_TOKEN=true), then build the MV3 extension into dist/. 

git clone https://github.com/vadymstroiu/LectureLens-AI.git
cd LectureLens-AI
cp .env.example .env
npm install && npm run build
3

Load Unpacked in chrome://extensions

Enable Developer mode in chrome://extensions, click Load unpacked, select dist/, open any YouTube lecture, and click the LectureLens AI toolbar icon. 

chrome://extensions  →  Developer mode ON  →  Load unpacked → dist/
